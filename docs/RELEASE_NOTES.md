## 燕云琴笺 0.1.7

- 曲谱导出新增 MIDI 格式，保留 BPM、和弦、重叠音符、完整音长和空拍，并写入中文曲名及乐器编号。
- 新增钢琴、古琴、箜篌、箫、二胡、埙六种合成试听音色。参考 unsampled-piano 的模态建模方法，分别处理泛音、起音、衰减、共鸣、气息和揉弦。
- 在试听琴键栏切换音色，选择自动保存，并与 MIDI 录制窗口共用。输入试听跟随松键和分通道延音踏板，录音试听支持超过 6 秒的长音。
- 长录音分段排程，最多保留 64 个合成声部；停止和取消启动会清空排程。

音色为独立实现的本地合成近似，尚未用游戏原声校准。MIDI 文件保存音符和 GM 乐器编号，外部播放器使用自己的音源；古琴等民族乐器映射到相近的 GM 乐器。曲谱导出力度统一为 100，没有音高的纯按键命令保留空拍。

提供 Windows x64 安装包和 macOS Apple Silicon DMG、签名更新包。实体 MIDI 键盘、macOS 音频与游戏接收待现场验收。macOS 使用 ad-hoc 签名，Windows 安装包未配置 Authenticode；应用会校验 Tauri 更新签名。
