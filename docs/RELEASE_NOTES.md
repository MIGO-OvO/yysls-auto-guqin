## 燕云琴笺 0.1.6

- 新增 MIDI 设备输入：连接键盘后录制演奏，保留全音域、复音、力度、通道和延音后的音长，可导出 MIDI。
- 支持将 88 键演奏录音转换为可编辑的 36 键曲谱。转换先根据音高、力度、音长和声部连续性选择旋律，再保留音级并调整八度；导入钢琴 MIDI 文件也使用这一算法。
- 录制面板可对比试听原曲与转换结果，调整速度和网格，并将结果另存为新曲目。设备断开或关闭面板后，录音在本次运行中保留；退出应用前可导出 MIDI 保存原始录音。
- 快捷键默认为 F11 开始、暂停或继续，F12 停止。点击设置输入框后直接录制下一组按键，支持 Ctrl、Alt、Shift、Command / Windows 组合键和 Escape 取消，并保留已有自定义设置。
- 曲库每行直接显示导出和删除图标，悬浮时显示提示。

转换在本地运行，结果为单声部。复杂伴奏、交叉声部与内声部旋律仍需试听和编辑。MIDI 输入用于录制后转换，录制时不向游戏发送按键。

提供 Windows x64 安装包和 macOS Apple Silicon DMG、签名更新包。实体 MIDI 键盘、macOS CoreMIDI 与游戏接收仍待现场验收。macOS 使用 ad-hoc 签名，Windows 安装包未配置 Authenticode；应用会校验 Tauri 更新签名。
