## 燕云琴笺 0.1.5

- 仅构建 Windows x64 和 macOS Apple Silicon，移除 macOS Intel 构建、安装包与更新目标。

- 修复旧设置让升级后仍显示深色的问题：首次迁移切换为米色，之后保留手动选择的主题。
- 移除曲库中的松枝画作，保留曲名栏的远山。

- 默认采用米色主题，以松绿 #4A6741 标识操作、选中与播放状态。
- 曲名栏保留淡墨远山，素材随应用离线分发。
- 删除品牌副标题、重复说明和常驻操作提示，详细用法放入帮助与悬浮提示。

- 修复 Windows 更新安装被语言选择对话框阻塞的问题，保留简中、英文安装器文本。
- 发布资产统一使用 ASCII 文件名，更新清单与 GitHub 下载地址一致。
- 下载更新和等待安装时保留更新日志。
- 增加隔离 Windows runner 中的原生演奏与更新安装、重启联测。

- 编排器与演奏器整合为 Rust + Tauri 2 桌面应用。
- 深浅主题、自定义标题栏与 36 键钢琴卷。
- 保留 JSON、MIDI、简谱、键位链及 TXT 命令，支持音符编辑、试听、撤销重做与曲库保存。
- Rust 独立演奏线程、暂停松键、停止清理、目标选择、全局快捷键和系统托盘。
- Windows Win32 与 macOS Quartz 输入适配；后台定向输入列为实验性，游戏接收未验证。
- GitHub Releases 签名更新：版本检查、更新日志、下载进度与确认安装。
- 修复低 BPM、四分网格下 1ms TXT 命令的导入与保存校验。

macOS 产物使用 ad-hoc 签名，尚未完成 Developer ID 签名与 Apple 公证。Windows 安装包未使用 Authenticode 证书。Tauri 更新包使用独立密钥签名并由客户端校验。
